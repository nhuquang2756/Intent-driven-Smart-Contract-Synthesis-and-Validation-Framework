01 · Vấn đề

LLM không đủ để
sinh hợp đồng on-chain

Hợp đồng Marlowe trên Cardano cần đúng tuyệt đối — một lỗi logic = ADA bị khóa vĩnh viễn. LLM đơn thuần không thể đảm bảo điều này.

  • Không thể kiểm chứng logic
  • Timeout sai thứ tự → ADA stuck
02

Intent Drift

  • User nói 60% → code sinh 50%
  • Không có cơ chế phát hiện
  • Contract pass spec nhưng sai nghĩa

No Traceability

  • Hộp đen hoàn toàn

  • Không thể audit sau deploy
02 · Giải pháp

Hybrid: LLM + Formal
Verification

LLM đảm nhiệm hiểu ngôn ngữ và sinh code. Formal checker đảm nhiệm kiểm chứng. Hai thứ không bao giờ bị nhầm lẫn.

LLM làm gì

  • Đọc hiểu tiếng Việt (Node 1)
  • Định hình cấu trúc logic (Node 2)
  • Sinh mã Marlowe DSL (Node 3)
  • Giải thích lỗi cho user (Node 4)

Formal checker làm gì

  • Kiểm tra mọi nhánh có Close
  • Timeout ordering theo spec §4.2
  • Số dư không âm (ledger rule)
  • PASS/FAIL — không phải LLM đoán

Intent Alignment

  • Snapshot ý định tại Node 1
  • So sánh AST với snapshot
  • Chạy TRƯỚC formal checker
  • Back-translation cho user confirm

🔁 Vòng lặp trong — Intent Loop

Node 2 → Node 3 → Intent Check → nếu fail quay về Node 2 re-generate blueprint.
Lỗi: sai parties count, sai share, sai deadline.
Max 5 retries trước khi hỏi lại user.

🔁 Vòng lặp ngoài — Formal Loop

Chỉ chạy sau khi Intent pass. Nếu Formal fail → quay về Node 3 re-gen với error context.
Lỗi: timeout ordering, missing Close, balance âm.
Max 3 retries.

04 · Các Node

4 Agent chuyên biệt

N1

Intent Parsing Agent

  • LLM đọc hiểu tiếng Việt
  • Extract: parties, shares, deadline, quorum
  • Ghi Intent Snapshot vào Shared State
  • Yêu cầu làm rõ nếu thiếu thông tin
N2

Game Theory & Logic

  • Nash equilibrium · incentive alignment
  • Sinh FSM: states + transitions
  • Định nghĩa invariants cho Node 4
  • Pre-check tổng shares = 1.0
N3

Marlowe Generator

  • Template matching từ thư viện pattern
  • Lắp ghép primitives: When/Pay/Choice
  • Self-check cú pháp trước khi gửi N4
  • Re-gen với error context khi FAIL
N4

Verifier — Static Analyzer

  • All branches → Close check
  • Timeout ordering (Marlowe spec §4.2)
  • RAG lookup → cite source vào log
  • 3-layer error: machine/dev/user
